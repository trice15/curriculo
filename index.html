Mural de Avisos

Aplicação web para publicar e editar os avisos e recados da turma. Os avisos são carregados de uma API pública, com mensagens de carregamento e de erro.

Minha participação: criei os componentes (formulário, lista e cartão de aviso), a validação do formulário e o tratamento de falhas da API.

React · Vite · JavaScript · API REST

Gerenciador de usuários

Aplicação que lista, cria, edita e exclui usuários consumindo uma API REST. As requisições ficam em um módulo próprio e os erros viram mensagens claras (404, 500, falha de rede).

Minha participação: desenvolvi as telas, o módulo de requisições, o cancelamento de chamadas com AbortController e a exclusão com retorno ao estado anterior em caso de erro.

React · Vite · JavaScript · API REST

Ver código no GitHub

API da Biblioteca

API para controlar livros, leitores e empréstimos, com cadastro, consulta, edição e exclusão. Calcula os dias de atraso e a contagem de dias úteis após o prazo de devolução.

Minha participação: organizei o projeto em rotas e controllers e programei as regras dos empréstimos.
